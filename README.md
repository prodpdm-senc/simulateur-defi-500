# Simulateur Défi 500 km · Plus de Millage

https://simulateur.plusdemillage.com

Simulateur d'autonomie pour le trajet du Défi 500 km de Plus de Millage :
rue Léger (LaSalle) → A-20 Est, sortie 314 (Lévis) → retour, à 110 km/h sur l'autoroute (509 km).

- Véhicules et cotes : RNCan (Données ouvertes et outil de recherche 2027), coefficients Road Load de l'EPA.
- Météo : Open-Meteo, en direct (vent, température, pression, humidité, précipitations à l'heure de passage).
- Bornes : base RNCan/AFDC, OpenStreetMap et ajouts vérifiés (Recharge Sprint), mises à jour chaque semaine par GitHub Actions.
- Carte : © contributeurs d'OpenStreetMap.

Site statique (HTML/JS, aucune compilation).
